# 給下一手維護者：請先看這裡

你收到的 ZIP 是「學校 ESG 指數」網站的程式碼及維護文件。這個 ZIP **不包含原持有人的 Manus 登入資料、管理員密碼、資料庫密碼、API key、JWT secret、環境檔或正式資料庫內容**。

## 你只需要做三件事

第一，將 ZIP 解壓縮，交給懂得維護 Node.js／React／MySQL 網站的開發者。不要把 ZIP 內任何檔案公開上載到網上。

第二，請開發者先閱讀 `handover/README.md`、`handover/ENVIRONMENT.md`、`handover/DATA-AND-DEPLOYMENT.md` 及 `handover/OPERATIONS.md`。他們會知道如何安裝、測試、設定資料庫和部署網站。

第三，如果要保留現有學校帳戶及提交記錄，請把「資料庫及檔案儲存交接」交給機構指定的安全技術人員處理；如果只需要程式碼，開發者可以建立全新的資料庫和管理員帳戶。

## 非技術持有人不需要交出的資料

你不需要交出自己的 Manus 密碼。你只需把這個 ZIP 交給下一手，並透過另一個安全渠道向機構指定技術人員提供必要的服務擁有權轉移安排。真正的密碼和 API key 不應放入 ZIP、電郵正文或普通聊天訊息。

## 目前交接限制

ZIP 只包含程式碼和文件。它不會自動帶走現有學校帳戶、學校提交、報告檔案、資料庫、網站網域或 Manus 專案權限。要保留這些內容，必須另外完成正式的資料及服務權限移交；要完全不保留原有資料，則由新維護者建立新資料庫及新管理員帳戶。

## 接收後驗收

請下一手確認可以在自己的帳戶和自己的電腦上安裝、啟動及測試網站；確認無需使用原持有人的登入資料；確認新管理員帳戶可以正常使用；完成驗收後，再由機構安排舊帳戶、舊密碼及舊服務權限的撤銷和憑證輪換。
